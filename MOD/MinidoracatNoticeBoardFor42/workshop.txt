description=[h1]📢 Minidoracat Notice Board for B42[/h1]
description=[h3]By Minidoracat[/h3]
description=
description=[hr][/hr]
description=
description=An in-game server notice board: server owners write notices as Markdown files, and saved changes are pushed to online players, who open the board with one click on an on-screen icon.
description=
description=[h2]📦 Requirements[/h2]
description=[list]
description=[*] Required: [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3789836701]Minidoracat UI Library for B42[/url] (listed under Required Items; the mod won't load without it)
description=[*] Works in singleplayer and multiplayer; in multiplayer the server must enable this mod
description=[*] Supported version: Build 42.20.2+
description=[/list]
description=
description=[h2]🚀 Quick start[/h2]
description=[olist]
description=[*] Server owners: enable the mod and start the server once; the notice folder and starter examples are created automatically
description=[*] Edit the examples or add notice files; saved changes are pushed to online players automatically
description=[*] Players: click the floating speaker icon to open or close the board; a red dot means unread notices
description=[/olist]
description=
description=[h2]✨ Features[/h2]
description=[list]
description=[*] [b]Markdown notices[/b]: laid out in game; bold and italic are shown as colors
description=[*] [b]Edit and it updates[/b]: no server restart; admins can reload with one click
description=[*] [b]Voice alerts[/b]: new notices are announced by Stacy or Yui, in Chinese, English or Japanese; server owners can swap in their own recorded line (see the full guide)
description=[*] [b]Document tree and custom categories[/b]: one notice per file in a collapsible sidebar with expand-all / collapse-all
description=[*] [b]Multilingual notices[/b]: offer as many languages as you like; players follow their game language or switch manually
description=[*] [b]Images in notices[/b]: PNGs sync to players automatically, with no texture-pack mod needed
description=[*] [b]One-click example rebuild (admins)[/b]: writes a full Traditional Chinese or English example set for reference
description=[/list]
description=📖 [b]Folder locations, file naming, categories, images, the Markdown syntax table and FAQ:[/b] [url=https://steamcommunity.com/workshop/filedetails/discussion/3789836823/586187095760095724/]Notice Board Guide: Server Owner Manual & Markdown[/url]
