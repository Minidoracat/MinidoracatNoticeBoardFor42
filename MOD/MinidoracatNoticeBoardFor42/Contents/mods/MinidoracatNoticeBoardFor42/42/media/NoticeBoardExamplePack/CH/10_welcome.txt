# 歡迎使用公告欄

這則公告是面板工具列上的「重建範例」按鈕產生的：管理員選了 CH，伺服器就把這個檔案
直接寫進 `NoticeBoard/CH/10_welcome.txt`。它是**正式公告**，使用 CH 公告語系且符合可見
規則的玩家現在就看得到。請直接改成自己的歡迎詞，或整篇換掉。這三則公告的 EN 版只差
一次按鈕：再開一次選單、選 EN 就會產生。

## 檔案放在哪裡

公告放在伺服器的 `Zomboid/Lua/NoticeBoard/`，不放在 MOD 裡面，所以改公告永遠不必重新
發布 MOD。伺服器每輪輪詢會重新讀檔，並把變更推送給所有在線玩家。

```text
Zomboid/Lua/NoticeBoard/
    README.txt          給管理員看的說明，不是公告
    categories.txt      宣告分類目錄（可選）
    images/             PNG 圖檔，會同步給每位玩家
    EN/
        10_welcome.txt
        10_news/
            20_markdown_showcase.txt
        20_rules/
            30_server_rules.only.txt
    CH/
        10_welcome.txt
        10_news/
            20_markdown_showcase.txt
        20_rules/
            30_server_rules.only.txt
```

`NoticeBoard/` 底下的正式公告語系目錄一律使用 PZ 語系代碼：`EN`、`CH`、`JP`、`PTBR`
等等；`images/` 是保留的工具目錄，不是語系，而根層的 `README.txt` 與 `categories.txt`
根本不是公告——掃描只讀語系目錄與 `categories.txt` 已宣告的分類目錄。語系目錄再往下
一層才是分類，而分類**只有被 `categories.txt` 宣告過才存在**。遊戲的目錄 API 無法列出
子目錄，所以沒宣告的資料夾等於不存在，裡面的公告不會出現，連錯誤訊息都不會有。
`categories.txt` 只「宣告」目錄、不會建立目錄，資料夾請自己建。

## 檔名與排序

- `.txt` 與 `.md` 都讀得到，解析能力完全相同。這些公告是 `.txt`，因為遊戲的寫檔
  API 不允許建立 `.md`。
- 檔名格式用 `<數字>_<ascii 名稱>.txt`，而且要留間隔：用 `10_`、`20_`、`30_`，日後
  才能插入 `15_event.txt` 而不必替所有檔案改名。
- 公告先依開頭數字排序，數字相同再依檔名排序；沒有數字前綴的排在最後。分類的排序規則
  一樣，看的是分類 key 開頭的數字。
- 檔名只能用 ASCII：英文字母、數字、`_` 與 `-`，最長 128 字元。中文請寫在檔案內容裡，
  不要寫進檔名。
- 檔名就是公告的穩定 ID：每個語系目錄裡必須用完全相同的檔名，而且同一語系內即使分屬
  不同分類也不得重複。
- 已讀狀態是以檔名當鍵，所以**改檔名等於變成一則全新公告**：看得到它的玩家會再收到一次
  通知、提示音與未讀紅點。沒有「靜默改名」這種機制。
- 側欄顯示的名稱取自檔案裡第一個 `#` 標題；沒有 `#` 標題時直接顯示完整檔名。

## 哪些玩家看得到哪一份

規則只有一條：**DefaultLanguage 目錄裡沒有標記 .only 的每一份檔案，都是全體共用的底稿；
玩家自己語系目錄裡的同名檔案會覆蓋上去。**

以 DefaultLanguage 設成 `EN` 為例：

- `EN/` 與 `CH/` 都有這個檔名：CH 玩家看 CH 版，其他人看 EN 版。
- 只有 `EN/` 有：**每一位**玩家都看得到，內容是英文，不管他讀什麼語系。
- 只有 `CH/` 有：只有 CH 玩家看得到。

所以 DefaultLanguage **不是**「找不到才去翻的備援目錄」，它是鋪給所有人的底稿——這正是
只寫一種語言的伺服器要的行為。

分類只改變側欄分組，不改變可見範圍。

## `.only` 標記

檔名寫成 `30_server_rules.only.txt` 時，這份檔案**永遠不會**被鋪成其他語系的底稿，
就算它放在 DefaultLanguage 目錄裡也一樣。這是在預設語系目錄裡表達「這份只給讀這個
語系的人看」的唯一方法。

標記的形狀是「副檔名前面那一段剛好是 only」：`x.only.txt` 算、`x.only.md` 算、
`20_only.txt` 不算、`x.onlyy.txt` 不算。

檔案內容不影響可見範圍。在標題裡寫「限中文」只是文字而已；決定誰看得到的只有兩件事：
檔案放在哪個語系目錄，以及檔名有沒有 `.only` 標記。

## 開始寫第一份公告之前

- 先看「最新消息」分類裡的 `20_markdown_showcase.txt`：本 MOD 解析的所有語法都在裡面，
  而且全是實際可運作的示範，可以對照原始文字檔一起看。
- **不要用 emoji**。檔案、雜湊與網路同步都能正確處理 emoji，但遊戲用預先烘焙的點陣
  字型繪製文字，不會回退到作業系統的 emoji 字型，所以 emoji 會變成問號、或是完全不
  繪製。請改用文字、`NoticeBoard/images/` 裡的 PNG，或 Minidoracat UI Library 的共用
  圖示。
- 玩家可以在面板工具列自行選擇公告語系；管理員在同一排還會看到「重新載入」與「重建
  範例」兩個按鈕。
