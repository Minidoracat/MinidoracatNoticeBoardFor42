# 伺服器規則

簡短版：玩的時候記得別人也存在。全部只有五條，沒有「沒看到」這種藉口。

1. **不破壞他人財產。** 不要拆、不要偷、不要把別人的基地圍起來。不是你蓋的門就不要開。
2. **不作弊。** 物品生成器、MOD 選單、加速外掛，第一次就永久停權；把帳號借給用外掛的人
   也一樣。
3. **安全區禁止 PvP。** 出生城鎮與交易站是安全區，其他地方一律風險自負，損失不補償。
4. **一個團隊一座基地。** 在入口立牌標示。閒置滿三週的基地，其他人可以接手。
5. **保持聊天室可用。** 歧視性字眼、騷擾與洗頻看到就刪，累犯連人一起處理。

違規的代價依序是：角色、基地、帳號。管理員不在聊天室辯論——對處置有意見請到 Discord 談。

> 維護會在這個公告欄與 Discord 提前至少一小時公告。維護期間請先登出：角色掛在線上
> 可能掉裝備，甚至整個存檔位一起壞掉。

有問題請在遊戲內找管理員，或到這裡（請換成你自己的網址）：

[伺服器 Discord](https://example.com/discord)

---

以下是給編輯這份檔案的管理員看的，正式發布前請刪掉：

這份檔案叫 `30_server_rules.only.txt`。`.only` 這一段的意思是它**永遠不會**被鋪成其他
語系的底稿——只有讀這個語系的玩家看得到。如果你希望「沒有自己翻譯的語系」都退回讀這
一份，就把 `.only` 拿掉。

有翻譯的語系目錄請沿用完全相同的檔名；另外記得改檔名等於讓所有看得到它的玩家重新收到
一次通知。

規則不要用 emoji 裝飾。遊戲用預先烘焙的點陣字型繪製文字，沒有作業系統字型的
fallback，emoji 會變成問號或完全不繪製。可靠的做法是用文字、`NoticeBoard/images/`
裡的 PNG，或 Minidoracat UI Library 的共用圖示。
