# Welcome to the notice board

This notice was generated by the "Rebuild examples" button in the panel
toolbar: an admin picked EN, and the server wrote this file straight to
`NoticeBoard/EN/10_welcome.txt`. It is a live notice: players eligible to read
EN notices can see it immediately. Edit it into your own welcome message or
replace it entirely. The CH versions of these three notices are one press away:
open the button menu again and pick CH.

## Where the files live

Notices live in the server's `Zomboid/Lua/NoticeBoard/` folder, never inside the
mod, so editing them never needs a mod update. The server re-reads them every
poll cycle and pushes the changes to everyone online.

```text
Zomboid/Lua/NoticeBoard/
    README.txt          notes for the admin, not a notice
    categories.txt      declares the category folders (optional)
    images/             PNG files, synced to every player
    EN/
        10_welcome.txt
        10_news/
            20_markdown_showcase.txt
        20_rules/
            30_server_rules.only.txt
    CH/
        10_welcome.txt
        10_news/
            20_markdown_showcase.txt
        20_rules/
            30_server_rules.only.txt
```

Every live notice language folder under `NoticeBoard/` uses a PZ translation
code: `EN`, `CH`, `JP`, `PTBR` and so on. `images/` is a reserved utility
folder, not a language, and the two root files `README.txt` and
`categories.txt` are not notices at all: the scanner only reads language
folders and the category folders declared in `categories.txt`. A folder one
level below a language is a category, and a category exists only if
`categories.txt` declares it. The game's directory API cannot list folders, so
an undeclared folder is invisible and its notices never show up - not even as
an error. `categories.txt` declares folders, it does not create them; create
them yourself.

## File names and order

- `.txt` and `.md` are both read and parse identically. These notices are
  `.txt` because the game's file writing API refuses to create `.md`.
- Name files `<number>_<ascii-name>.txt` and leave gaps: `10_`, `20_`, `30_`
  lets you insert `15_event.txt` later without renaming anything.
- Notices are sorted by that leading number, then by name; files with no number
  go last. Categories are ordered the same way, by the number in their key.
- File names are ASCII only: letters, digits, `_` and `-`, 128 characters at
  most. Your language belongs in the content, not in the file name.
- The file name is the stable ID of a notice. It must be identical in every
  language folder, and unique inside one language even across categories.
- Read state is keyed on that name, so renaming a file turns it into a brand
  new notice for everyone who can see it: notification, sound and unread dot
  all fire again. There is no silent rename.
- The sidebar entry is the first `#` heading in the file. With no `#` heading
  it falls back to showing the whole file name.

## Which players see which file

There is one rule. **Every file in the DefaultLanguage folder that is not
marked .only is a shared base copy, and a file with the same name in the
player's own language folder overrides it.**

With DefaultLanguage set to `EN`:

- The file exists in `EN/` and in `CH/`: CH players read the CH text, everyone
  else reads the EN text.
- The file exists only in `EN/`: every player sees it, in English, whatever
  language they read in.
- The file exists only in `CH/`: only CH players see it.

So DefaultLanguage is not a "looked at only when nothing else is found" folder.
It is the base copy laid out for everybody - which is exactly what a server
that writes only one language wants.

Categories regroup the sidebar and nothing else. They never change who can see
a notice.

## The .only marker

A file named `30_server_rules.only.txt` is never laid out as a base copy for
another language, not even from the DefaultLanguage folder. That is the only
way to say "this one is for readers of this language alone" inside the default
language folder.

The marker is the segment right before the extension: `x.only.txt` counts,
`x.only.md` counts, `20_only.txt` does not, `x.onlyy.txt` does not.

Nothing inside the file changes visibility. Writing "EN only" in the title is
just text. Only two things decide who sees a notice: which language folder it
sits in, and whether the name carries the `.only` marker.

## Before you write your first notice

- Read `20_markdown_showcase.txt` in the News category. It demonstrates every
  syntax this mod parses, with live examples you can compare against the raw
  text file.
- Do not use emoji. The files, the hashes and the network sync all handle them
  correctly, but the game draws text from pre-baked bitmap fonts and never
  falls back to an operating system emoji font, so an emoji comes out as a
  question mark or as nothing at all. Use plain words, a PNG from
  `NoticeBoard/images/`, or the shared icons of the Minidoracat UI Library.
- Players can choose their notice language from the panel toolbar; admins also
  get Reload and Rebuild examples buttons there.
