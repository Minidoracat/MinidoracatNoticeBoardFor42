## Notices can show images

![Sample image](media/ui/NoticeBoard/nb_sample.png =240x)

The image above ships with this mod and is here to prove image syntax works.

To use your own images, drop the PNG files into the server's `NoticeBoard/images/`
folder and reference them with `![caption](images/your-file.png)` — the server syncs
them to every player automatically, so **you do not need a separate texture pack mod**.

Display size is optional: `=600x200` (width x height), `=600x` (width only),
`=x200` (height only). Size limits, the file count cap and how updates are picked up
are all documented in `NoticeBoard/images/00_README.txt`.

Images cannot be loaded from the internet - that is an engine limit.
